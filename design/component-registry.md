## §0 通用约定

- **文件**：fileKey `2059170750769684481`，page `0:2`。所有组件均为**本地组件**。
- **定位**：`relay.getNodeByIdAsync(nodeId)`。
- **属性 key**：带 `#uid` 后缀且随机，运行时从 `inst.mainComponent.componentPropertyDefinitions` 读取，按**基础名**匹配（⚠ `inst.componentProperties` 在 setProperties 前为空）。
- **标签显隐**：渲染器用 `setTagInstance`（找嵌套实例 → 无值时 `node.visible=false`），**不依赖 BOOLEAN 属性**（删子节点会静默清理 BOOLEAN refs）。

## §4 拼接模型（以画板 17:1747 为准）

### 4.1 骨架

```
页面根 (FRAME, VERTICAL)       width 375 | padding 16 | fills WHITE
└── 内容堆叠 (VERTICAL)         FILL 宽 | itemSpacing 6      ← 区块间统一 6
    ├── [header 区块]
    ├── [body 区块]
    ├── [h1 区块]
    ├── [card / row_v 区块] × N
    └── [all_products 区块]
```

### 4.2 各区块包裹规则

| 区块 | 组件 | wrapper 参数 |
|---|---|---|
| **header** | 加载完成 | VERTICAL wrapper，padding 下 **13** |
| **body / h2** | 正文 / 二级标题 | 无 wrapper，直接入堆叠 |
| **h1** | 一级标题 (+ 更多按钮) | HORIZONTAL wrapper，padding 上 **9**，SPACE_BETWEEN，itemSpacing 12 |
| **card** | P_card_h | VERTICAL wrapper，padding 上下各 **3** |
| **row_v** | P_card_v ×1-2 | HORIZONTAL wrapper，itemSpacing **7** |
| **all_products** | 全部商品按钮 | 无 wrapper，直接入堆叠 |
